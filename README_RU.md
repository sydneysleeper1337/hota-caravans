# Физические караваны для Heroes III: HotA 1.8.0

Экспериментальный мод добавляет физическую доставку существ в **Heroes of Might and Magic III: Horn of the Abyss 1.8.0**. Откройте принадлежащий вам город и нажмите `K`: можно заказать существ из захваченных внешних жилищ, резерва другого города или его гарнизона.

Первое нажатие **«Отправить»** показывает полную цену. Ресурсы списываются только после второго, подтверждающего нажатия. После этого на карте появляется повозка, которая проходит до восьми клеток за игровой день.

## Возможности

- Окно в стилистике Heroes III находится внутри игры и не переключает приложение.
- Деньги никогда не списываются без отдельного подтверждения.
- Существа первого уровня из внешних жилищ бесплатны, как в обычном окне жилища; в городах они остаются платными.
- Кнопка **«Все»** выбирает максимум доступных существ, который игрок может оплатить имеющимися ресурсами.
- Герои, нейтральные существа и гарнизоны задерживают караван на пути.
- Если существует свободный обход, караван выберет его даже при большей длине; ждать он будет только при отсутствии свободного маршрута.
- Владелец может забрать войска, противник — атаковать караван.
- После полного забора войск пустая повозка автоматически исчезает.
- Движение и удаление тележек выполняются в основном потоке игры, чтобы не конфликтовать с обработкой объектов HotA.
- Клавиша вызова настраивается в `Caravan.ini`.
- Карты менять не нужно, исходные EXE игры не перезаписываются.

## Совместимость

Сборка предназначена только для проверенных файлов **HotA 1.8.0**. Их SHA-256 приведены в английском README и проверяются установщиком. Обычные SoD/Complete, ERA/WoG, VCMI и другие версии HotA не поддерживаются. Маршрут между поверхностью и подземельем пока не строится. Сетевая и hot-seat игра не проверялись.

## Установка

1. Скачайте `release/Caravan_HotA_1.8.0.zip`.
2. Распакуйте папку `Caravan_HotA_1.8.0` непосредственно в папку HotA, рядом с `h3hota.exe`.
3. Запустите `Установить.bat`.
4. Запускайте созданный файл `h3hota Caravan HD.exe`.

Установщик создаёт отдельные копии запуска и не изменяет оригинальные EXE. Для удаления запустите `Удалить.bat`. Пока версия экспериментальная, используйте отдельное сохранение.

## Смена клавиши

Измените `Caravan.ini` в папке игры, например `Hotkey=F8`, и перезапустите игру. Поддерживаются буквы, цифры, `F1`-`F24`, `SPACE`, `TAB`, `HOME`, `END`, `INSERT`, `DELETE`, стрелки, `PAGEUP` и `PAGEDOWN`.

## Сборка из исходников

Нужен 32-битный MinGW-w64 C++ компилятор:

```powershell
.\build.ps1
```

Либо укажите путь явно: `.\build.ps1 -Compiler 'C:\path\to\g++.exe'`. DLL появится в `dist\Caravan.dll`. Подробности реализации и пункты для проверки находятся в [TECHNICAL.md](TECHNICAL.md).

Это неофициальный проект сообщества. В репозитории нет EXE игры, карт, сохранений или извлечённых игровых ресурсов.
